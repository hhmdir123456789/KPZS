# 📐 数学之美：动态公式可视化科普馆
> **The Beauty of Math: Interactive Visualization Museum**

一款面向大众的、零门槛的数学与物理公式动态可视化科普工具。基于 HTML5 Canvas 构建，无需下载安装，点开即玩。通过 30 个动态彩色粒子与霓虹光网，生动演绎 100 个经典公式的几何之美。

## 🔬 科普价值 (Educational Value)
* **将数学具象化**：100 个公式涵盖数学曲线与物理系统，让抽象符号“活”起来。
* **动态参数调节**：拖动滑块即可改变花瓣数（玫瑰线）、偏心率（开普勒轨道）、阻尼系数（阻尼振荡）等。
* **可视化波形叠加**：通过傅里叶方波、锯齿波，直观理解波的叠加原理。
* **互动性教学**：老师可用于课堂演示，学生可手动观察轨迹变化。

## ✨ 核心功能 (Features)
* **100 个公式库**：包含 50 个数学曲线 + 50 个物理系统。
* **4 套视觉主题**：经典霓虹、赛博朋克、极光、单色，一键切换。
* **高级搜索与收藏**：支持关键词搜索，本地永久保存收藏夹与最近浏览记录。
* **一键截图导出**：保存高光画面，方便分享或插入 PPT。
* **演示模式**：隐藏所有 UI，只保留纯粹的光网动画，适合投屏展示。
* **移动端完美适配**：大触控区域，适配刘海屏与底部手势条。

## 🎮 操作指南 (How to Play)
* **PC 端**：鼠标拖动滑块调节参数，键盘 `空格` 暂停，`←` `→` 切换公式，`ESC` 退出演示模式。
* **移动端**：手指拖动滑块，双击画布重置轨迹。

## 🛠️ 技术栈 (Tech Stack)
* 原生 HTML5 Canvas API（无第三方库依赖）
* 极坐标系与参数方程纯函数映射
* LocalStorage 数据持久化
* 动态分辨率适配与响应式布局
